주요 기능

온디바이스 검색·다운로드

yt-dlp + ffmpeg가 앱에 내장되어 있어 서버 없이 YouTube를 검색하고 MP3로 저장합니다. 커버 이미지와 태그까지 삽입됩니다.

로컬 라이브러리

다운로드한 곡을 플레이리스트와 즐겨찾기로 정리하세요. 모든 데이터는 기기에만 저장됩니다.

백그라운드 재생

알림 컨트롤과 대기열을 지원합니다. 화면을 꺼도 음악이 이어집니다.

자동 업데이트 점검

앱을 열 때 yt-dlp 초기화·무결성 검사·최신 버전 확인을 진행해 다운로드 실패를 줄입니다.

프라이버시

로그인·추적·광고가 없습니다. 다운로드한 파일은 Android/media/com.yump3/yump3/에 저장되어 파일 관리자로 바로 접근할 수 있습니다.

FAQ

Play 스토어에 없나요?

현재는 APK 직접 설치만 지원합니다. 서명이 debug 키라 스토어 업로드는 불가하며, 테스트/개인 사용 용도입니다.

어떤 기기에서 실행되나요?

Android 7.0(API 24) 이상, arm64-v8a 기기에서 동작합니다. 대부분의 최근 안드로이드 폰이 해당됩니다.

다운로드가 실패해요.

앱을 열 때 자동으로 yt-dlp를 점검·업데이트합니다. 그래도 실패하면 My Page → “yt-dlp 업데이트”를 눌러주세요. 실패한 항목을 탭하면 상세 오류를 볼 수 있습니다.

파일은 어디에 저장되나요?

내장 저장소/Android/media/com.yump3/yump3/ 에 제목 [영상ID].mp3 형식으로 저장됩니다.

라이선스는?

GPL-3.0. 번들된 youtubedl-android(GPL-3.0) 때문에 앱 전체가 GPL-3.0으로 배포되며, 전체 소스는 GitHub에 공개되어 있습니다.
